================================================================================
RENTTRACK - SYSTEM FEATURES & FUNCTIONAL SPECIFICATIONS
================================================================================

1. SYSTEM OVERVIEW
--------------------------------------------------------------------------------
RentTrack is a full-stack, real-time boarding house management system for small-scale to medium-scale boarding houses.

Architecture Stack:
  - Frontend: Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS
  - Backend:  Node.js, Express.js, PostgreSQL (pg / node-postgres)
  - Security: RFC 7519 JWT, bcrypt password hashing, Google OAuth 2.0 (GIS)
  - Real-time / Services: Nodemailer, Node-Cron, WebSockets/Presence Tracking


================================================================================
2. AUTHENTICATION & ACCESS CONTROL
================================================================================
  - Dual Authentication Methods:
      * Standard Email & Password authentication.
      * Google Sign-In via Google Identity Services (GIS) SDK with a built-in 
        Material 3 account chooser fallback.
  - Role-Based Access Control (RBAC):
      * Administrator / Owner: Full operational and financial management access.
      * Tenant / Resident: Dedicated resident portal for billing, maintenance, 
        and room details.
  - Tenant Verification Gate:
      * Newly registered residents are placed in a 'Pending' verification status.
      * Prevents unapproved access until property administrators vet the application.
  - Embedded Legal Policies:
      * Inline, animated Terms & Conditions and Privacy Policy modals built 
        directly into the login and signup flows (no redirects).
  - API Protection & Security:
      * IP-based rate limiting on sensitive authentication routes.
      * Cryptographically signed RFC 7519 JWT tokens with permission payloads.
      * CORS protection and sanitized security headers.

3. ADMINISTRATOR PORTAL (/admin)
================================================================================

A. Executive Operations Dashboard (/admin/dashboard)
  - Real-Time KPI Ribbon: Live aggregate counters for Total Revenue, Active 
    Residents, Available Rooms, and Pending Maintenance Tickets.
  - Visual Floor & Room Matrix: Real-time multi-column grid displaying all 
    building floors, unit availability, and status counters (Full, Occupied w/ Beds, 
    Vacant, Maintenance).
  - Inline Announcement Composer: Create, edit, and broadcast property announcements 
    directly from the dashboard with modal transitions.
  - Offline Activity Catch-Up: Notification bell dropdown summarizing resident 
    registrations, payments, and ticket submissions that occurred while offline.

B. Tenant Management Directory (/admin/tenants)
  - Search & Multi-Filter Engine: Real-time search by name/email with filters 
    for Room Type, Floor Level, and Lease Status (Active, Pending, Moved Out, Declined).
  - Resident Profile Dossier: Side drawer displaying complete tenant info, 
    assigned room, monthly rent, move-in dates, and emergency contacts. Can be 
    dismissed for full-screen table width.
  - 1-Click Application Approval / Rejection: Immediate workflow to approve or 
    decline pending resident accounts with automated notification triggers.
  - Quick Action Deep Links: 1-click shortcuts to edit tenant details, issue custom 
    invoices, send instant chat messages, or record tenant move-out.

C. Room & Bed Capacity Manager (/admin/rooms)
  - 5-Column Visual Bed Matrix: Room cards with an arranged 5-column bed grid 
    displaying vacant vs. occupied beds, with custom vertical scroll for 
    high-capacity suites (>10 beds).
  - Floor Grouping: Rooms grouped by building floor with aggregate occupancy chips.
  - Maintenance Mode Toggles: 1-click toggle to set rooms into maintenance mode, 
    automatically restricting new move-ins.
  - Room Configuration Modals: Add and edit rooms, rental models (Whole Room vs. 
    Bedspace), floor assignment, base rental pricing, and custom amenities.

D. Billing, Utility Submeters & GCash Settlements (/admin/billing)
  - Automated Monthly Billing Engine: Batch-generate recurring monthly invoices 
    calculated from base rent and itemized utility submeters.
  - Submeter Utility Tracking: Individual utility charge breakdown for water, 
    electricity, and custom property surcharges.
  - GCash Online Settlement: Integrated downloadable property GCash QR codes for 
    resident scanning.
  - Payment Verification Modal: Review resident-uploaded transaction receipts, 
    reference numbers, and proof screenshots with 1-click approve/reject actions.
  - Printable Invoices & Receipts: Detailed, downloadable billing statement sheets 
    with payment history and outstanding balance tracking.

E. Maintenance Request Management (/admin/requests)
  - Standardized Work Orders: Automatic generation of formatted ticket IDs 
    (REQ-YYYYMMDD-XXXX).
  - Lifecycle Workflow: Track and transition tickets across stages (Pending -> 
    In Progress -> Resolved).
  - Categorization & Priority: Organize requests by category (Plumbing, Electrical, 
    Air Conditioning, Structural, Internet) and priority (High, Medium, Low).
  - Direct Resident Follow-Up: Fast navigation to resident profile or chat from 
    any work order.

F. Messenger & Communication Hub (/admin/chat)
  - Real-Time Resident Chat: Direct two-way messaging between administrators 
    and individual residents.
  - Embedded Maintenance Ticket Cards: Interactive work order summary cards 
    rendered directly inside conversation message feeds.
  - Presence Indicators: Live status dots showing resident online/offline activity.

G. CCTV Live Security Monitoring (/admin/cctv)
  - Multi-Camera Grid View: Live video feeds for on-premise security monitoring.
  - Fullscreen Camera Mode: Expand any single camera feed for focused inspection.
  - Camera Status Badges: Visual indicator for active, recording, and offline cameras.

H. Financial Reports & Analytics (/admin/reports)
  - Comprehensive Financial Audits: Monthly revenue summaries, collection rates, 
    and delinquent balance overviews.
  - Occupancy Analytics: Occupancy percentage trends across rooms and bedspaces.
  - Printable / Exportable Reports: Clean, printer-friendly reports for property owners.

I. System Activity Logs & Audit Trail (/admin/activity-logs)
  - Immutable Event Log: Full chronological history of tenant registrations, 
    room reassignments, payment verifications, and ticket resolutions.
  - User & Timestamp Tracking: Detailed metadata recording who performed each action.

J. Property Settings & Admin Profile (/admin/settings, /admin/profile)
  - Single-Page Administrative Hub: Unified settings page covering property rules, 
    utility billing defaults, and administrator account credentials.

4. RESIDENT / TENANT PORTAL (/tenant)
================================================================================

A. Resident Overview Dashboard (/tenant/dashboard)
  - Active Balance Banner: Prominent card showing total balance due, breakdown, 
    and due date countdown.
  - Assigned Unit & Bed Overview: Displays room number, floor, room type, and 
    move-in date.
  - Community Notices & Advisories: Real-time broadcast advisories from property management.
  - Emergency Hotlines: Quick access to facility emergency contacts and administration.

B. Online Payments & Statements (/tenant/payments)
  - Instant GCash Payment Flow: Scan or save the property's GCash QR code, input 
    transaction reference numbers, and upload payment screenshots.
  - Transparent Utility Breakdown: Clear itemization of Base Rent, Water Submeter, 
    Electric Submeter, and Miscellaneous Fees.
  - Digital Receipts: Automatically generated, printable payment receipts upon 
    payment verification.
  - Payment History: Chronological log of past invoices, paid amounts, and statuses.

C. Room Details & Amenities (/tenant/rooms)
  - Room Specifications: Detailed overview of room capacity, designated bed slot, 
    and room type.
  - Amenities & Inclusions: Icon-mapped inventory of amenities (Wi-Fi, Aircon, 
    Study Table, Private Bathroom, etc.).
  - Maintenance History: History of past maintenance requests filed for the assigned unit.

D. Maintenance Helpdesk (/tenant/requests)
  - Submit Work Orders: Submit repair tickets with title, description, category, 
    urgency level, and photo attachments.
  - Real-Time Progress Tracker: Follow ticket status through Pending, In Progress, 
    and Resolved states.
  - Cancel Pending Requests: Residents can withdraw pending requests if an issue resolves.

E. Resident Messaging & Chat Popup (/tenant/chat)
  - Floating Chat Widget: Accessible floating chat popup on all tenant portal pages.
  - Fullscreen Chat Workspace: Dedicated messaging thread with property administrators.

F. Resident Profile & Preferences (/tenant/profile, /tenant/settings)
  - Personal Information Dossier: Manage registered name, contact number, and address.
  - Emergency Contacts: Dedicated emergency contact record with relationship details.
  - Password & Security: Self-service password changes with strength verification.
  - Theme Customization: Dark Mode and Light Mode toggle options.
  - Support Tickets Center: File customer care inquiries separate from maintenance.


================================================================================
5. AUTOMATED BACKGROUND SERVICES & DAEMONS
================================================================================

A. Automated Billing Cron Daemon (cronService.js)
  - Scheduled background worker automatically executing billing generation on the 
    1st of every month for active tenants.
  - Syncs submeter utility charges and base rent into pending monthly statements.

B. Email Dispatcher Service (emailService.js)
  - Automated HTML email dispatch via SMTP / Nodemailer.
  - Due Date Reminders: Automated friendly reminders sent prior to invoice due date.
  - Overdue Payment Notices: Urgent notices sent when an invoice passes its due date.
  - Account Status Notices: Automated emails dispatched upon resident approval.

C. Presence Tracking Service (presenceService.js)
  - Monitors socket and HTTP activity to maintain real-time online/offline states.
  - Records last-active timestamps for security and communication readiness.

D. Unique Identifier Generators (requestNumberGenerator.js)
  - Generates collision-resistant, human-readable work order numbers 
    (REQ-YYYYMMDD-XXXX) and invoice IDs.

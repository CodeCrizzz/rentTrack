3. PROCESSES & DATA STORES SPECIFICATIONS
========================================================================================================================

------------------------------------------------------------------------------------------------------------------------
3.1 PROCESS SPECIFICATIONS (1.0 TO 6.0)
------------------------------------------------------------------------------------------------------------------------

1. Process 1.0: Authenticate User
   - Primary Inputs  : Login Credentials (email, password) from Administrator, Tenant, or Boarding House Owner.
   - Data Store Link : D1 User Database (Read user hash, role, status; Write login timestamp).
   - Logic           : Validates credentials with bcrypt, generates JWT role token, routes user to authorized portal.
   - Primary Output  : Validated Auth Session Token; Login Audit Event written to D5 Communication Logs.

2. Process 2.0: Manage Tenant Records
   - Primary Inputs  : Tenant Application Data, Profile Updates, Move-Out Notices from Administrator.
   - Data Store Link : D2 Tenant Database (Read/Write tenant details, emergency contacts, move-in/out dates).
   - Logic           : Registers new applicants, evaluates approval/rejection, manages active boarder profiles.
   - Primary Output  : Updated Tenancy Record; Bed Assignment & Room Allocation Request to Process 3.0.

3. Process 3.0: Track Room Occupancy
   - Primary Inputs  : Room Allocation Request from Process 2.0; Room Specs & Rate Updates from Administrator.
   - Data Store Link : D3 Room Database (Read/Write capacity, current occupants, room status: Available/Occupied).
   - Logic           : Calculates real-time bed availability, updates floor matrix, enforces max capacity constraints.
   - Primary Output  : Occupancy Data and Monthly Base Rental Rates transmitted to Process 4.0 (Process Billing).

4. Process 4.0: Process Billing
   - Primary Inputs  : Active Occupancy Data & Rates from Process 3.0; Monthly Node-cron trigger & Utility readings.
   - Data Store Link : D4 Billing & Payment Database (Write itemized bills; Read previous overdue balances).
   - Logic           : Calculates total = rent + water + electricity + late penalties; flags overdue unpaid invoices.
   - Primary Output  : Itemized Billing Statements delivered to Tenant; Invoices queued to Process 5.0.

5. Process 5.0: Make Online Payment
   - Primary Inputs  : Payment Request from Tenant; Billing invoice record from D4.
   - External Link   : PayMongo API (Payment Intent, tokenization, GCash/Maya/Card gateway, webhook callbacks).
   - Data Store Link : D4 Billing & Payment Database (Insert payment record; Deduct balance; Update bill to Paid).
   - Logic           : Authenticates payment via PayMongo; updates balance; issues confirmation alert to D5.
   - Primary Output  : Payment Receipt & Settled Balance to D4; Transaction Confirmation delivered to Tenant.

6. Process 6.0: Generate Reports
   - Primary Inputs  : Report Query Filters from Administrator or Boarding House Owner.
   - Data Store Link : D3 Room Database (Read occupancy rates) & D4 Billing Database (Read collection metrics).
   - Logic           : Computes Billed vs. Collected Cashflow, collection efficiency %, and property occupancy trends.
   - Primary Output  : Executive Summaries, Revenue Trends, and Occupancy Reports to Boarding House Owner.
